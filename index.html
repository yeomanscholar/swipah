How Swipah works

  1. Pick a folder (Chrome/Edge, or Chrome on Android).
  2. Set your swipes: each direction is a tag, and each tag is a folder inside the one you picked.
  3. Swipe (or drag with the mouse, or use arrow keys). Files move into the tag’s folder. In “Tag several” mode, a file can get more than one tag: it moves to the first and is copied into the others.
  4. Recap: see everything you sorted, then export a bundle an AI can learn your style from.

Keys: ←→↑↓ swipe · Space skip · Z undo · Enter done (multi-tag) · R rename · Esc leave rename box

Private by design: Swipah runs entirely in your browser. No uploads, no accounts, no tracking. A log of your tags is saved to .swipah/log.jsonl in your folder.

Nothing gets deleted. “Trash” is just a _trash folder you can empty yourself.
